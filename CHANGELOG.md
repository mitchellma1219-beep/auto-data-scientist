# Changelog

## 0.1.0 (unreleased)

- Loading of CSV, TSV, XLSX, Parquet, SQLite and DuckDB into a locked in-memory DuckDB.
- Column profiling and a documented data-quality score.
- Guarded read-only SQL with explanations; rule-based question translator.
- Correlations, segments, time-series summary, cohort retention, KPI role detection.
- Classification / regression against a no-skill baseline with leakage screening.
- Forecasting with naive baselines and rolling-origin backtests.
- Executive report with reproducible artefacts; `ads` CLI; `auto-data-scientist` Agent Skill.
- Streamlit dashboard (`app/streamlit_app.py`) over the same engine: Data, Explore, Ask,
  Predict, Forecast and Report, with built-in synthetic samples, uploads, cached results and
  downloads (one zip or single files). Bound to localhost; no sign-in.
- Plotly charts as pure functions in `charts.py`: histogram, category and segment bars, time
  series with forecast and range, correlation and cohort-retention heatmaps, candidates
  against the baseline, hold-out comparison, permutation importance, quality components.
- Model selection on large tables uses a seeded, class-proportional sample of 20,000
  training rows; the selected model is refitted on all training rows and scored on the whole
  hold-out. `--selection-rows` changes the size; the report states the sample.
- Text from the data is escaped in the report, the CLI output and chart labels, so names and
  values cannot inject Markdown or HTML.
- `ads report` gained `--keep`, `--freq` and `--selection-rows`; `reproduce.sh` records them
  and the business problem, and regenerates an identical report.
- Uploaded CSV and Parquet tables are named after the uploaded file, not the stored one.
- Friendly explanations for every expected error (`errors.explain`); a dataset can be shared
  between threads (`Dataset.lock`); artefacts as one deterministic zip (`bundle_artifacts`).
- `.claude/skills/auto-data-scientist` links the skill as a project skill.
- Demo under `demo/`: sample reports, offline chart pages and dashboard screenshots, all
  regenerated by scripts from synthetic data.
- ARCHITECTURE.md, CONTRIBUTING.md and PORTFOLIO.md.
- Fixed: an unknown `--date-col` crashed with a `KeyError`; a newline or pipe in a column
  name broke a table in the report; concurrent queries on one dataset failed.
- 322 tests; CI on Python 3.11, 3.12 and 3.13 with lint, types, coverage gate and audits,
  now including the dashboard script.
